# SightLint v0.1.0-alpha.1 (unpublished)

This immutable tag records a failed first release-workflow attempt. It is not a supported release,
and no GitHub prerelease was published from it.

The package job created a deterministic source archive/checksum and a draft release. The
cross-platform jobs then failed before extraction because their read-only workflow tokens could
not access draft release assets. Run 34000128047 and issue #47 preserve the evidence. The tag was
not moved or reused; ADR 0038 changes the transport and makes `v0.1.0-alpha.2` the first publishable
source alpha.
