# SightLint v0.1.0-alpha.2

This is the first evidence-backed, source-only SightLint alpha. It is intentionally narrow.

## Included

- deterministic Rust Artifact IR validation, canonicalization, rules, reports, and CLI;
- bounded PNG parsing/raster acquisition and advisory image-region inspection;
- a process-isolated Playwright adapter for repository-contained local fixtures;
- three advisory zero-setup Web rules for selected native evidence;
- one `sightlint-web-check` capture/check/source-navigation/fix/rerun workflow;
- versioned conformance, pixel, image-inspection, Web acquisition/rule, and product corpora;
- dual `MIT OR Apache-2.0` licensing.

The release contains one deterministic source archive and its SHA-256 checksum. Build locally with
locked Cargo/npm dependencies using `docs/release.md`.

## Security, privacy, and provenance

The deterministic kernel is local-only. The current browser path blocks external requests and
hosted processing, records provenance, uses bounded temporary capture storage, and does not
serialize full HTML. The archive contains only files tracked by the released commit. GitHub
Actions verifies its checksum, safe extraction, locked dependency licenses, Rust workspace, Node
package, and Linux product path before publication. A final release job compares the verified
workflow-artifact files with the draft release assets byte-for-byte before publishing.

Checksums detect corruption but are not a signature. No telemetry, model call, hosted service,
database, or private/customer fixture is included.

## Known limitations and non-claims

- The public Web corpus is one fictional, maintainer-reviewed application family with visible
  labels and no protected holdout.
- Recommended Web findings remain advisory. Model-only or pixel-heuristic evidence cannot block.
- Native structure and rendered pixels are both retained; pixel-content identity, complete hit
  regions, semantic peer inference, and arbitrary-project compatibility remain incomplete.
- `inspect-image` retains `uxVerdict: cantTell`; its narrow region/gap observations are not general
  screenshot or UI/UX accuracy.
- Browser product E2E is Linux-only with Node 20–24 and the pinned Chromium build.
- No prebuilt binary, crates.io package, npm package, Homebrew formula, container, signature, or
  artifact attestation is provided.

Success on the committed fixture/corpora proves regression behavior within those contracts. It
does not prove WCAG conformance, universal UX quality, autonomous-agent quality, or representative
real-world precision.
