# Glossary

**Adapter**  
A sensor that reads one artifact or platform and emits validated Artifact IR observations.

**Artifact**  
A web screen, mobile screen, slide, document page, image, diagram, or other analyzable visual
or interactive product.

**Artifact IR**  
SightLint's medium-neutral intermediate representation between observation and policy.

**Canvas**  
A coordinate space such as a viewport, screen, page, slide, or frame.

**Evidence**  
A source-linked observation supporting an IR value or rule result.

**Hit box**  
The region that can receive a pointer or touch interaction.

**Ink/render box**  
The region occupied by pixels that are actually rendered under a defined effects policy.

**Layout box**  
The region allocated by a native layout or source format.

**Perception**  
Probabilistic OCR, detection, classification, hierarchy reconstruction, or language-model
interpretation.

**Rule**  
A versioned, executable obligation with explicit applicability, evidence, and outcomes.

**Trusted kernel**  
The deterministic Rust code that validates IR, evaluates rules, and creates reports.
